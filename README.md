# PageSwap

A one-page website for PageSwap Reading Circle, a campus book club where readers meet every Friday at 4:00 PM at CISLT to swap finished novels and argue over plot twists. Built by Raheemah for GirlsTech Bootcamp 1.0.

## Features
- A greeting at the top that changes depending on the time of day
- A Dark Mode button that switches the colours of the whole page
- Three genre cards loaded from a JavaScript array
- A swap form where you can add your book and watch it show up in the meetup list right away and a counter that updates automatically
